# Deva code runner

For local development, install `python -m pip install -r runner/requirements.txt`, then start the API with `npm run runner`. It uses Waitress on `127.0.0.1`. Node.js 22.13 or newer is required for the runtime permission flag.

The Flask API exposes `/api/execute` for JavaScript function tests and for compiling/running full programs in JavaScript, Python, Java, and C++. Multi-language runs go to a compiler service. Set `PISTON_API_URL` in the root `.env` to the base URL of your self-hosted Piston instance (for example `http://192.168.1.20:2021`); Flask asks it for `/runtimes`, picks the newest version per language, and posts each program to `/execute`. Add `PISTON_API_KEY` if the instance requires a Bearer token. Without `PISTON_API_URL`, runs fall back to Judge0 through `JUDGE0_API_URL`, which defaults to `http://127.0.0.1:2358` locally. Set `JUDGE0_API_URL=https://ce.judge0.com` to use Judge0's public instance instead, which needs no key or whitelist but is limited to roughly 60 requests a minute and has no uptime guarantee. Both variables also need setting in Vercel Project Settings → Environment Variables for production. The configured compiler receives the submitted source code and standard input.

For local use, put `GEMINI_API_KEY=...` in the root `.env` file; the backend loads it, and the key never belongs in a Vite `VITE_*` variable. `GEMINI_MODEL` can optionally override the default `gemini-3.8-flash` model. On a Gemini 503, the tutor automatically tries `GEMINI_FALLBACK_MODEL` (default `gemini-3.6-flash`). For Vercel, add `GEMINI_API_KEY` and optional `GEMINI_MODEL` / `GEMINI_FALLBACK_MODEL` in Project Settings → Environment Variables. Python Function entry points are in `api/`, and the root `requirements.txt` installs Flask and the Gemini SDK. `https://codexsheet.in` is an allowed origin by default. Set `RUNNER_ALLOWED_ORIGINS` to a comma-separated list when using another production domain.

In another terminal, run `npm run dev`. Vite proxies `/api/execute` to Flask. Start the Flask process and your local Judge0 service before running programs in Deva. Production needs `JUDGE0_API_URL` configured in Vercel.
